# 画面一覧と画面遷移

画面は19個と共通の部品で構成する。ログイン後はマップ一覧（ホーム）から始まり、左のサイドバーで「マップ」「タスク」「カレンダー」「設定」の4つの区分を行き来する（B-09）。差別化の中心は、マップエディタの横にカレンダーを開く分割表示（B-10、P3）。

> 図「画面の構成 · 認証と4つの区分」は企画書（非公開）にある。必要になったら Mermaid で描き直す。

区分をまたぐ主な遷移は、次のとおり。

| 遷移元 | 遷移先 | きっかけ |
| --- | --- | --- |
| ログイン | マップ一覧（ホーム） | ログインの成功 |
| マップ一覧 | マップエディタ | マップを開く、新規作成、テンプレートから作成 |
| マップエディタ | カレンダーの分割表示 | 「カレンダー」ボタン（P3） |
| マップエディタ | 変更履歴 | 「履歴」ボタン |
| タスク一覧、カレンダー | マップエディタ（元のノード） | タスクや作業枠の「元のノードへ」 |
| カレンダー、分割表示 | 連携の管理 | 未接続・要再連携の案内から |
| どの画面でも | ログイン | リフレッシュトークンの失効 |

## 主要画面のワイヤーフレーム

画面の骨格だけを示す。見た目の細部は、UIの基盤（B-05）とデザインの基準（B-07）を決めたあとに詰める。

> 図「ワイヤーフレーム · マップエディタとカレンダーの分割表示（SC-10）」は企画書（非公開）にある。必要になったら Mermaid で描き直す。

サイドバーの「マ」はマップ、「タ」はタスク、「カ」はカレンダー、「設」は設定。分割表示を開いている間は、ノードの詳細パネル（メモ、装飾、タスク化）を閉じる。

> 図「ワイヤーフレーム · マップ一覧（ホーム、SC-05）」は企画書（非公開）にある。必要になったら Mermaid で描き直す。
