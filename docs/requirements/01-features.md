# 機能一覧

MindMeisterの「個人の編集体験」を網羅し、共同編集・コメント・共有はバックログにする（A-03）。そのうえで、タスク化、カレンダー連携、AIスケジューリングをThinkronos独自の機能として強化する。各機能の詳細は、次の章「機能要件」の各IDを参照する。

## MindMeisterとの比較

| 機能グループ | MindMeister | Thinkronos | フェーズ | 要件 |
| --- | --- | --- | --- | --- |
| 編集の基本 | トピックの追加と移動、キーボード操作、Undo | 採用 | P1 | MM-01〜07 |
| レイアウト | マインドマップ、組織図、リスト（混在も可） | マインドマップから始め、組織図とリストを後で追加する（B-03） | P1、PX | MM-05、MM-23 |
| 配置 | 自動整列と自由配置 | 自動整列を基本とし、浮いたトピックだけ自由配置にする（D-11） | P1、PX | MM-05、MM-12 |
| つながり線 | 任意の2つのトピックを結ぶ線 | 採用 | PX | MM-13 |
| 装飾 | 形、枠線、線の色、画像、絵文字、Markdown | 採用。色はP2、それ以外はPX | P2、PX | MM-08、MM-14、MM-15、MM-20 |
| メモ | トピックごとのメモ | 採用 | P2 | MM-08 |
| アウトライン | マップと文章形式の切り替え | 採用 | PX | MM-16 |
| フォーカスモード | 画面の飾りを隠して集中する | 採用 | PX | MM-17 |
| プレゼンテーション | 枝やトピックをスライドにする | 採用 | PX | MM-21 |
| テンプレート | 用途別のテンプレート | 数種類から始める | PX | MM-22 |
| テーマ | 配色とスタイルのセット | ライト・ダークに加えて数種類 | PX | MM-25 |
| エクスポート | PDF、画像、Markdown、Word、PowerPointなど | Markdown、画像、PDF、Mermaid。WordとPowerPointは対象外 | P2、P3、PX | MM-10、MM-11、MM-24 |
| インポート | テキスト、FreeMindなど | Markdownとテキスト。FreeMindとXMindはバックログ | P2 | MM-10 |
| 変更履歴 | 版の一覧と復元 | 操作ログ（D-02）で実現する | PX | MM-18 |
| マップの整理 | 一覧、フォルダ、ゴミ箱 | 一覧、検索、ゴミ箱。フォルダはバックログ | P1、P2、PX | MM-01、MM-09、MM-19 |
| AIによる生成 | プロンプトからのマップ生成 | 採用し、子ノードの提案と要約も加える | P1、P2 | AI-01〜06 |
| タスク化 | MeisterTaskとの連携 | 独自：ノードをタスクにし、カレンダーへ自動で配置する | P2、P3 | TK、CL、AI-07〜09 |
| 共同編集・コメント・共有 | 同時編集、コメント、招待 | バックログ。データだけ備える（A-02） | ― | ― |

MindMeisterの機能は、2026年11月時点の公開情報による（[製品レビュー](https://project-management.com/mindmeister-software-review/)、[MindMeisterのブログ](https://focus.meisterlabs.com/?p=29377)）。

## Thinkronos独自の機能

- 枝をタスクに変換し、所要時間と期限の案をAIが付ける（AI-05、TK-01〜06）。
- 空き時間へ作業枠を自動で提案し、承認したらカレンダーに書き込む（AI-07〜09、CL-07）。
- 予定から元のノードと、その周りの文脈にたどれる（差別化の軸）。
- Google、Outlook、Slack、Notion、GitHub、MCPとの連携（IN-01〜12）。

# 機能要件

機能要件は全82件で、優先度はMust・Should・Couldの3段階。フェーズ（P1〜P3、PX、P4）は「開発計画」の章で定義する。

## 認証・ユーザー（AU）

| ID | 要件 | 優先度 | フェーズ |
| --- | --- | --- | --- |
| AU-01 | メールアドレスとパスワードで登録・ログインできる（JWTのアクセストークン＋リフレッシュトークン） | Must | P1 |
| AU-02 | ログアウトでき、リフレッシュトークンを失効できる | Must | P1 |
| AU-03 | 所属するワークスペースのデータだけにアクセスでき、他人のマップや予定にはアクセスできない | Must | P1 |
| AU-04 | タイムゾーン、稼働時間帯（曜日ごとの開始・終了）、予定間のバッファを設定できる | Must | P2 |
| AU-05 | 認証方式をCognitoなどの外部IdPに差し替えられる（認証ポートの抽象化） | Should | P4 |
| AU-06 | 登録時に確認メールを送り、リンクを開くとアカウントが有効になる | Must | P1 |
| AU-07 | パスワードを忘れたとき、メールのリンクから再設定できる（1回限り、短い有効期限） | Must | P1 |
| AU-08 | ログインに一定回数失敗すると、一時的にロックする | Must | P1 |
| AU-09 | パスワードとメールアドレスを変更できる | Should | PX |
| AU-10 | 退会でき、すべてのデータが削除される | Should | PX |
| AU-11 | 登録できるメールアドレスを制限できる（P1は許可リスト、P4で招待制。C-18） | Must | P1 |

| AI-06 | マップを横断して、意味の近いノードを探せる（ベクトル検索＋全文検索） | Should | P2 |
