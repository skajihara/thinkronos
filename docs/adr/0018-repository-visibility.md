# 0018 リポジトリの公開範囲

## 状態

承認済み、2026-11-23（企画書の CI/CD の方針を記録したもの）

## 背景

ブランチ保護やルールセット、Environments（デプロイ先ごとの承認と秘密情報）を使いたい。GitHub の無料プランで、費用をかけずに CI を回したい。ポートフォリオとして見せたい（A-04）。

## 比べた選択肢

| 案 | 特徴 |
|---|---|
| 非公開（無料プラン） | 秘密情報の混入の被害が小さい。無料プランの非公開リポジトリでは、ルールセットや Environments の一部が使えず、Actions に月の実行時間の上限がある |
| 非公開（有料プラン） | 機能は使えるが、費用がかかる |
| 公開 | 無料プランでブランチ保護・ルールセット・Environments が使え、標準のランナーでの Actions の実行時間に上限が無い。秘密情報を一度でもコミットすると公開される |

## 決定

公開する。ライセンスは MIT。

## 理由

- 無料で、ブランチ保護・ルールセット・Environments と、上限の無い Actions を使える（[GitHub Actions billing](https://docs.github.com/en/billing/concepts/product-billing/github-actions)：公開リポジトリでの標準のランナーは無料。確認日 2026-11-23）。
- ポートフォリオとして、設計判断（ADR）と開発の流れをそのまま見せられる。

## 影響

- 秘密情報は、pre-commit と CI の gitleaks で二重に防ぐ。`.env` は Git の管理外で、Claude Code の設定でも読ませない。
- 非公開の情報（企画書、意思決定ログ、会社に関わる記述）はリポジトリに入れない（K-01）。
- 公開の Issue と PR に、個人情報や連携先のアカウントの情報を書かない。
