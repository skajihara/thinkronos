# ADR（設計判断の記録）

設計判断とその理由を、後から読み返せるように残す。文書は日本語で書く。

## 書き方

ファイル名は `NNNN-題.md`（番号は4桁、題は英小文字とハイフン）。見出しは次の順にする。

| 見出し | 書くこと |
|---|---|
| 状態 | 提案中／承認済み／置き換え済み のいずれかと日付（例：承認済み、2026-11-23） |
| 背景 | 何を決める必要があったか。関係する要件の番号 |
| 比べた選択肢 | 候補と、それぞれの特徴 |
| 決定 | 何に決めたか。1〜3行 |
| 理由 | なぜそうしたか。主要な計測値を含める。出典を明記する |
| 影響 | 本実装での条件、残る課題、未確認の点 |
| 参照 | 試作のブランチ、Issue、関連するADR |

- 数値は試作の `RESULT.md` から引用する。ADRのために新たに計測しない。
- 決定を変えるときは、既存のADRを書き換えず、新しいADRを書いて元の状態を「置き換え済み」にする。
- 試作のコードはADRに取り込まない（ブランチを参照する）。
