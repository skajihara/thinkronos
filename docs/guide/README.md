# 使い方

機能ごとの「使い方」のページ。実装の前に書き、Kiro の仕様（`.kiro/specs/`）の入力にする。完成したら、そのまま操作マニュアルにする（K-07）。

| ページ | 内容 | 要件 |
|---|---|---|
| [map.md](map.md) | マインドマップを作って編集する | MM-01〜07 |

## 書き方

- 利用者が画面で何をし、何が起きるかを書く。実装の方法（API、テーブル）は書かない。
- 要件IDを見出しの横に書き、要件の文は複製しない。
- まだ決まっていないことは「未定」と書き、Issue（ラベル `decision`）に回す。
