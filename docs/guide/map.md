# マインドマップを作って編集する

対象の要件：MM-01〜MM-07（P1）。画面：マップ一覧（SC-05）、マップエディタ（SC-06）。

## マップを作る・開く・整理する（MM-01）

1. ログインすると、マップ一覧が開く。自分が使えるマップが、更新の新しい順に並ぶ。
2. 「新しいマップ」を押すと、名前の無いマップが作られ、エディタが開く。中心のトピックの文字を入力する状態になっている。
3. 一覧でマップを選んで開く。名前の変更と削除は、一覧の各行のメニューから行う。
4. 削除したマップは一覧から消える。復元はゴミ箱（MM-19、PX）から行う。P1 では、削除したマップは復元できないが、データは残る（論理削除）。

## トピックを足す・書く・消す（MM-02）

- 中心のトピックは、マップに1つだけある。消すことはできない。
- トピックを選んで **Tab** を押すと子のトピック、**Enter** を押すと下に兄弟のトピックができ、すぐに文字を入力できる。**Shift＋Enter** で上に兄弟ができる。
- 文字を直すときは、トピックをダブルクリックするか、選んで **F2** を押す。選んだまま文字を打ち始めても、書き換えが始まる。
- 入力中は **Enter** で確定、**Esc** で取り消す。トピックの中で改行するときは **Shift＋Enter**。
- 日本語の変換中に Enter を押しても、確定は変換の確定として扱い、トピックは増えない。
- トピックを選んで **Delete** を押すと、そのトピックと子孫がすべて消える。

## トピックを動かす（MM-03）

- トピックをドラッグして別のトピックの上で離すと、その子になる（親の付け替え）。
- 兄弟の間で離すと、並び順が変わる。キーボードでは **Ctrl＋↑／↓** で兄弟の中の順番を入れ替える。
- 自分の子孫の上には動かせない（離しても元に戻る）。

## 枝をたたむ（MM-04）

- 子のあるトピックの端の丸を押すか、選んで **Space** を押すと、枝をたたむ／広げる。
- たたんだ枝には、隠れている子の数が出る。
- たたんだ状態はマップに保存され、次に開いたときも同じになる。

## 見る場所を変える（MM-05）

- トピックは、中心から左右に自動で並ぶ。新しい第1階層のトピックは、少ない側に置かれる。
- ホイールで拡大・縮小、ドラッグ（何も無い所）で移動する。**＋／−** で拡大・縮小、**F6** で中心に戻る。
- 拡大率と表示位置は、マップごとにこのブラウザに保存する。別の端末やブラウザで開くと、中心から表示される。

## キーボードだけで使う（MM-06、B-08）

操作の体系は MindMeister に合わせる（B-08）。

| キー | 動作 |
|---|---|
| 矢印 | 隣のトピックへ選択を移す（左右は親子、上下は兄弟） |
| Tab ／ Insert | 子のトピックを足す |
| Enter ／ Shift＋Enter | 下／上に兄弟のトピックを足す |
| F2、文字の入力 | 文字を書き換える |
| Esc | 入力を取り消す。選択を外す |
| Delete | トピックと子孫を消す |
| Space | 枝をたたむ／広げる |
| Ctrl＋↑／↓ | 兄弟の中の順番を入れ替える |
| Ctrl＋Z ／ Ctrl＋Y（Ctrl＋Shift＋Z） | 元に戻す／やり直す |
| ＋／−、F6 | 拡大・縮小、中心に戻る |

## 元に戻す（MM-07）

- **Ctrl＋Z** で、直前の操作を1つずつ戻す。**Ctrl＋Y** でやり直す。
- 1回の操作（例：枝ごとの削除、ドラッグでの付け替え）は、まとめて1回で戻る。
- 戻せるのは、このタブで自分がした操作だけ。マップを開き直すと、履歴は消える（D-15、ADR 0011）。
- 同じマップを別のタブで変えていた場合は、その変更を残したまま、このタブの操作だけを戻す。戻す操作は、逆の操作を新しく記録することで行う（D-15）。

## 保存

- 操作はその場でサーバーに保存される。保存ボタンは無い。
- 通信が切れている間の操作は送れない。オフラインでの編集はしない（ADR 0016）。

## 上限

- トピックの文字は1,000字まで。1つのマップに置けるトピックは2,000個まで。超えると追加できず、理由が表示される。

## 別のタブで同じマップを開いているとき

- 別のタブでの変更は、画面に戻ったときと30秒ごとに取り込まれる。同じ項目を両方で変えたときは、後から保存したほうが残る（D-13）。
