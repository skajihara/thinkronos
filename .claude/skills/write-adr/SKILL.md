# ADRの作成

1. `docs/adr/README.md` を読み、書き方と一覧を確認する。`docs/adr/` の既存ファイルから、番号が重複しないか確かめる（番号の指定がなければ、Issueやロードマップの指定を尋ねる。推測しない）。
2. ファイル名は `NNNN-題.md`（4桁、英小文字とハイフン）。
3. 見出しは次の順：**状態、背景、比べた選択肢、決定、理由、影響、参照**。
   - 状態：提案中／承認済み／置き換え済み と日付（例：承認済み、2026-11-23）。承認は人が決める。通常は「提案中」で作る。
   - 理由：主要な計測値と出典を書く。数値は試作の `RESULT.md` から引用し、ADRのために新たに計測しない。
   - 試作のコードは取り込まず、ブランチを参照する。
4. `docs/adr/README.md` の一覧に1行足す。
5. 決定を変える場合は、既存のADRを書き換えず、新しいADRを書き、元の状態を「置き換え済み（NNNNで置き換え）」にする。
6. 本文は日本語で書く（コミットメッセージとPRタイトルは英語）。書いたら、`docs-consistency-checker` エージェントで一覧とのずれを確かめる。
